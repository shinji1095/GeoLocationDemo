# httpsアクセス

## openssl

自己署名証明書を作成する．

`openssl`を使って秘密鍵と公開証明書を作成する．

```shell
$ cd app
$ mkdir cert
$ openssl req -x509 -newkey rsa:4096 -nodes -keyout cert/key.pem -out cert/cert.pem -days 365
```

## mkcert

**1.インストール**
公式ページ（[mkcert releases](https://github.com/FiloSottile/mkcert/releases)）から**Windows用バイナリ**をダウンロード

**2.環境変数の設定**

`C:\Program Files`などに適当に`mkcert`フォルダを作成して，環境変数を設定する．

**3.ルートCA証明書をインストール**

```shell
mkcert -install
```

# アプリの実行

## Nodeサーバー

Node.jsを使ってWebsocketサーバーを構築している．httpとhttpsアクセス可能にし，xiaoはhttp，reactはhttpsアクセスをする．

以下のコマンドを使ってwebsocketサーバーを起動する．

```shell
node server.cjs
```

## Viteサーバー

`vite`を使ってhttpsアクセス可能なローカルサーバを作成する．


`npm`コマンドを使ってアプリを実行する．

```shell
$ npm run dev
```
